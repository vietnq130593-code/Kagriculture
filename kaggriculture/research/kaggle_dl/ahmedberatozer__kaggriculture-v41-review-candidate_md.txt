# Kaggriculture V41 — Review Candidate

**The original competitive protocol did not pass every gate.** This source beat
V39 and V40 in all 128 new direct games against each, and gained 110 wins over V39
in 3,200 independent games against working public policies. On 352 new current-elite
records it gained 20 wins, but the 95% team-level point interval was −1.14 to +12.22
percentage points. That confidence gate remains FAILED; no sample was redrawn.

This notebook produces a technically validated REVIEW archive for an informed
live-test decision. It is not a claim of certain superiority or a 2800+ rating.
The full results below include the failed gate and lower public cash/margins.
Running the notebook does not submit the agent to Kaggle.


V41 builds on our V39 agent. It combines Rayk Kretzschmar's public opening
sequence with rules that make the farming plan depend on available cash,
seeds and food. The objective is to win more matches; income and winning
margin are measured separately and may move in different directions.

The agent reserves the next morning's worker budget and keeps planting
requests within the seeds already owned. It can fund urgent wheat purchases
while preserving existing purchases and hires. An animal must have food
before its feeding action: an idle worker can collect it early, or a pickup
immediately after an unfunded feeding action can be moved before that feed.
The following observation confirms that the expected supplies arrived.

Market funding uses conservative price bounds. A first sale may finance later
orders only with products already in the shed after the current field actions.
Expected future harvests do not count as cash. Before dawn, the agent avoids
planting a seed that would die immediately without same-turn watering.

Validation includes games against running public policies, comparisons with
V39 and V40, and replay-based checks against elite opponents. Recorded actions
cannot react to a changed game, so replay results alone do not establish a
ladder advantage. The results below describe this exact source and its limits.

Run all cells to produce `submission_competitive_v41_REVIEW.tar.gz`. The notebook
contains the full source as plain text. Its default build needs no GPU,
installation, download or attached input and does not train or play games.
Set `RUN_GAME_CHECKS = True` to run four optional complete-game checks with
the official engine. Source and archive hashes verify the output files.

No live ladder score is guaranteed.
