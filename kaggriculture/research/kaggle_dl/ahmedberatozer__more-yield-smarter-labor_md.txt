# Kaggriculture V37 — More Yield, Smarter Labor

**Release candidate.** V37 adds finite crop fertilization projects, guarded warehouse sales and shared tomato-worker assignments to V36. It admits extra work only after the parent farm's committed requests are satisfied and only when its cost and action budgets fit.

The evidence is mixed: V37 gained 87 wins without losing an existing win on an older 512-game recorded field. On the independent 136-game field from 17 teams rated at least 2900, both versions scored 81 wins and 55 losses; V37 improved mean cash margin by 865.46 but added no net wins. That original qualification gate **failed**. A separate reacting-policy confirmation and technical checks are reported below. This is a candidate for live evaluation, not a guaranteed rating or proof of universal superiority.

In the separate new reacting test, V37 scored **1786/70/0 (96.23%)** versus V36's **1738/118/0 (93.64%)** across 1,856 games per version: **48 improved outcomes and 0 worse**, with **+1180.80** mean cash-margin gain. The whole-world outcome, margin and own-cash confidence gates passed. This supports a live trial while leaving the independent elite-field limitation intact.

**Import this notebook and run all cells.** The exact tested agent is embedded directly. The default build needs no attached input, download, training, installation or GPU. It writes `main.py` and `submission_competitive_v37.tar.gz` in `/kaggle/working`.

Optional full-game checks are off by default. Set `RUN_GAME_CHECKS = True` in the first code cell to play four smoke games with `kaggle-environments 1.32.7`. The submitted agent itself uses only the Python standard library. Kaggle queue time is separate from this notebook's execution time.
